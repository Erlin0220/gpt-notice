## 关键结果

- ChatGPT 页面流式输出不再直接触发插件 UI 重绘；插件根节点和加入队列按钮保持同一节点实例。
- 空输入、空闲、运行、暂停和兼容性阻塞状态下，加入队列按钮均可点击并给出明确结果。
- 空闲页面保存队列后默认暂停，不会隐式发送。
- 队列删除上移、下移和排序领域能力，按加入顺序执行；立即执行不改变其余待执行项相对顺序。
- 页面只残留隐藏旧输入框时视为兼容性阻塞，不读取或写入该节点。
- 诊断报告不包含聊天正文、队列正文、完整 URL、原始会话 ID、Tab ID、Cookie、Token、邮箱或本地路径。
- CI 与自动 Release 均增加锁文件安装、Playwright Chromium 和无登录浏览器冒烟门禁。
- 固定目录更新脚本包含 v0.7.0 新增运行文件。
