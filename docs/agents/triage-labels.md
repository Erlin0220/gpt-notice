# Triage Labels

工程技能使用五种固定分流角色。下表定义这些角色在本仓库 GitHub Issues 中对应的标签字符串。

| mattpocock/skills 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估和分流 |
| `needs-info` | `needs-info` | 等待报告者补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由无人值守 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或人工实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提到某个分流角色时，必须使用右侧对应的 GitHub 标签，不得临时创建同义标签。
